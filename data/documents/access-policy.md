# Application Access Policy

## Requesting application access

Employees must submit an access request through the internal access portal.

The request must include:

- Application name
- Business justification
- Requested access level
- Manager approval

Access requests are reviewed by the application owner. Standard requests are normally reviewed within two business days.

## Emergency access

Emergency access is allowed only for production incidents. The incident commander must approve the request, and the access must be removed after the incident is resolved.
